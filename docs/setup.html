初回セットアップ案内（PC 再現手順）

はじめて自分の PC で Giftia（検索 API と画面）を動かすときの 1本道ガイドです。2回目からは STEP 4（ターミナル1）と STEP 5（ターミナル2）だけで動きます。

⚠ はじめる前の大事な約束（秘密を守るルール）

  • .env（DB のホスト名・ユーザー名・パスワード）の中身は、GitHub・Slack・生成 AI（Claude Code / Codex 等）・スクショに絶対に貼らないでください。
  • 置き場所は C:\Services\giftia のように、OneDrive や Google ドライブの外にします（同期フォルダの中だと node_modules や .venv が壊れます）。

1. 初回セットアップ（STEP 1〜5）

1 リポジトリを clone する（最初の1回だけ）

PowerShell を開き、作業用フォルダを作って AR7ST/giftia をダウンロードします。

mkdir C:\Services -Force cd C:\Services git clone https://github.com/AR7ST/giftia.git cd C:\Services\giftia

2 バックエンド（検索 API）の仮想環境と .env を用意する

backend/ フォルダに入り、Python の部品箱（.venv）を作ってパッケージを入れます。続けて型紙（.env.example）を .env にコピーし、班で共有された DB 接続情報を自分の PC だけで記入します。

cd C:\Services\giftia\backend python -m venv .venv .\.venv\Scripts\Activate.ps1 pip install -r requirements.txt copy .env.example .env

※ PowerShell で「スクリプトの実行がシステムで無効…」と出たときは、一度だけ Set-ExecutionPolicy -Scope CurrentUser RemoteSigned を実行してから Activate.ps1 を打ち直します。

※ SSL 証明書（DigiCertGlobalRootG2.crt.pem）を C:\Services\certs\ 等に置き、backend/.env の DB_SSL_CA にスラッシュ区切り（/）でパスを書きます。

3 フロントエンド（画面）のパッケージと .env.local を用意する

giftia-frontend/ フォルダに入り、npm install で部品を入れます。

cd C:\Services\giftia\giftia-frontend npm install copy .env.example .env.local

※ giftia-frontend/.env.local の NEXT_PUBLIC_API_URL=http://localhost:8000 はそのまま使います（ここには秘密情報を絶対に書きません）。

4 【ターミナル1】検索 API（FastAPI・8000番）を起動する

1つ目の PowerShell 窓で API を起動し、開けっぱなしにします。

cd C:\Services\giftia\backend .\.venv\Scripts\Activate.ps1 uvicorn main:app --reload

確認：http://localhost:8000/api/health を開いて {"status":"ok","products":...} が出れば DB 接続まで成功です。

5 【ターミナル2】画面（Next.js・3000番）を起動する

2つ目の新しい PowerShell 窓を開き、画面を起動します。

cd C:\Services\giftia\giftia-frontend npm run dev

確認：http://localhost:3000 を開き、「検索」ボタンを押して商品カードが表示されればセットアップ完了です！

2. 動作確認チェックリスト

  • ✅ ターミナル1：行の先頭に (.venv) が付いていて、Uvicorn running on http://127.0.0.1:8000 と出ている
  • ✅ ヘルスチェック：http://localhost:8000/api/health で status: "ok" が返る
  • ✅ ターミナル2：http://localhost:3000 で Giftia の画面が開き、検索結果が最大 20 件表示される
  • ✅ Git 状態確認：git status を打ったとき、.env や .env.local が一覧に出てこない（.gitignore で守られている）
