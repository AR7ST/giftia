課題の進み具合・次の仕事・要件対応表

宿題の進み具合、これから着手する「次の仕事（担当者フィルター付き）」、および要求 → 要件 → 実装ファイル → PR → 確認結果の対応表です。

1. 次の仕事（これから作る機能・検証タスク）

担当者ボタンを押すと、そのメンバーが関わるタスクだけに絞り込めます。

FR-01：人数×1人あたり予算での検索と並び順（販売数→評価→商品ID）
担当：むっちゃん・タケ これから（Phase1）

人数と1人あたり予算から上限金額（budget_max）を計算し、在庫あり商品を「販売数 → 評価（NULLは末尾） → 商品ID」の順で返す。画面とAPIのつなぎ目（api.ts と backend/main.py）を同じPRで変更。

FR-02（残り）：商品カードへの説明文（description）表示と未設定時の「不明」表示
担当：むっちゃん これから（Phase1）

評価なしの「評価 不明」対応（PR #12 で完了）に続き、商品の特徴・説明文をカード上で比較できるようにし、情報がない項目は「不明」と明示する。

FR-03：選んだ最大3候補＋理由から相談文を作成・コピーする機能
担当：タケ・まいまい これから（Phase1）

検索結果から最大3件を選び、選んだ理由を添えて LINE 等にそのまま貼れる定型の相談文を生成・ワンタップでコピーできるようにする。

VR-01：説明しやすさ・相談しやすさの試用評価と最終発表準備
担当：まいまい・全員 4〜5週目

Phase1 の画面を班内で試用し、「候補の比較材料が揃うか」「同僚への相談文として使いやすいか」を検証して要求定義書6章・発表資料に反映する。
