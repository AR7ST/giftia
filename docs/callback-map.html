mapとコールバック関数

「配列の値を一つずつ関数へ渡し、返された結果を集めて、新しい配列を作る」のが map です。Giftiaの検索結果も、この仕組みで画面に並んでいます。

1. 基本の動き（数字の例）

const prices = [100, 200, 300];
const newPrices = prices.map(price => {
  return price + 50;
});
// newPrices は [150, 250, 350]

mapへ渡した関数（コールバック関数）を、mapが配列の値ごとに呼び出します。1回分の答え（return）はまずmapへ戻り、全部終わるとmapが新しい配列をまとめて返します。

sequenceDiagram
    participant 呼び出し元
    participant map
    participant コールバック関数
    呼び出し元->>map: prices.map(関数)
    loop 配列の値ごと
        map->>コールバック関数: 1つの値を渡す（例:100）
        コールバック関数-->>map: returnで答えを返す（150）
    end
    map-->>呼び出し元: 新しい配列 [150,250,350]

この最後のresults.map(...)が、1章の仕組みと同じです。届いた商品データ（配列）を1件ずつ受け取り、ResultCardという「コールバック」でカードに変換して並べています。

3. よくある質問

Q. returnを忘れるとどうなる？
A. 計算はしていても答えを返さないので、結果はundefinedになります。

Q. 商品が0件のときは？
A. 空配列に対してmapを呼ぶと、コールバックは1回も呼ばれず、空配列がそのまま返ります。

Q. mapが直接画面に表示するの？
A. いいえ。mapは新しい配列（Reactの要素の配列）を作るだけで、それを使って画面に反映するのはReactの役目です。
