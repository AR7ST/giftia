# 変更の解説を書く

公開ハブの変更履歴に載せる説明です。説明する変更と同じ PR で `change-notes/search-filters.md` のような新しいファイルを追加してください。ファイル名に使えるのは半角英小文字・数字・ハイフンです。すでにマージされた PR の解説を後から追加する場合は `pr-39.md` のように PR 番号を使います。両方ある場合は PR 番号のファイルが優先されます。

Markdown の見出し、段落、箇条書き、太字、インラインコードを使えます。ツリー図は、次のように `text` のコードブロックに記述します。変更ファイルの一覧は履歴から自動で生成されるので、解説には操作や表示がどう変わったかを書いてください。

PR がない過去のコミットには `commit-` に続けて GitHub に表示される完全なコミット ID をファイル名に使えます。

~~~markdown
## 変更前

利用者が見ていた表示や操作を書きます。

## 変更後

新しい表示や操作を書きます。

## 変化の流れ

```text
利用者が操作する
└─ 条件を確認する
   ├─ 条件を満たす → 新しい表示
   └─ 条件を満たさない → 案内を表示
```
~~~

公開ページに載るので、本名、秘密情報、教材の内容や DB の実データを含めないでください。
